# 王陆语料库听写练习

沿用原来的深色 UI，把教材词库、录音目录、页面样式和功能代码分开维护。

## 使用

在线访问：<https://ymir-twice.github.io/wanglu-dictation/>

在项目目录运行：

```bash
python3 -m http.server 8000
```

浏览器访问 <http://localhost:8000>。也可以把整个仓库部署到 GitHub Pages 等静态网站托管服务，无需构建、账号或后端。

词库通过独立 JSON 文件加载，不能只下载 `index.html` 或直接双击文件使用。请保留 `assets/` 和 `data/` 目录。

## 听写流程

1. 选择章节，点击「开始听写」。
2. 使用页面内的教材录音，支持暂停、拖动进度、前后 5 秒和倍速；也可以选本机 MP3，或切换「逐词朗读」。
3. 一边听一边输入。Enter 跳下一题；Alt + P 播放/暂停，Alt + R 重听。
4. 点击「完成」自动批改并保存。也可先点「批改」查看答案，此时答案锁定，点「完成」保存本次结果。重复点击不会重复记录错误次数。
5. 在「错词本」选择「只听错题」，或在章节页选择「只听本章错题」。答对后标记为已掌握；勾选「包含已掌握」可查看完整错题档案。

错题重听使用浏览器英语语音逐词朗读，不是从长录音中截取原声。英语语音可用性及是否需要网络取决于浏览器和系统设置。教材录音从来源仓库加载，网络不通时可以选择已下载的本地音频。

输入会自动保存为草稿。返回章节页或刷新后点击「继续上次未完成的听写」。教材音频位置会随草稿保存；刷新后需要手动开始播放，本地文件需要重新选择。新开练习会替换上一份草稿。

## 批改和错题

- 忽略大小写、首尾空格、多余连续空格；支持词条声明的答案变体与常见英美拼写。
- 数字题保留前导零，忽略数字间空格和千位逗号；日期支持日/月顺序和序数词后缀变化，不忽略年份差异。
- 单复数、漏词、连字符和空格词仍按答案判定，不进行模糊匹配。
- 错题按「章节 + 单词」保存，每次完成练习最多累计一次。相同词语在不同章节分别记录。
- 导出错词本或本次错题为 CSV，包含章节、标准答案、我的答案、释义、音标、错误次数、日期和掌握状态，Excel 可直接打开。
- 「导入数据」页面可导出完整 JSON 备份，或合并导入旧版/当前版备份。重复导入同一记录不会重复累计。

练习记录保存在当前浏览器的 localStorage，不会上传服务器。清除浏览器数据会丢失记录，请定期备份。新版自动读取旧站点同一来源下的 `wl3_hist` 和 `wl3_wb`；另一个域名或从 `file://` 迁移时，请先导出再导入。

## 词库与来源

目前提供 **74 个练习、9,431 条题目记录**。数量包括预测试、复现词语以及版本对照，不是去重后的单词量。

- 保留原有第 3、4、5、11 章词表，移除第 11 章误混入答案的「综合测试」标题。
- 新增第 2、6、7、8、9、10 章的 **2,108 条题目记录**，包括复数、拼写、数字、地址、日期、专业、动词与连接表达。新增词条保留教材 PDF 页码。
- 第 11 章配套 Excel 与扫描教材并非同一份完整词表。教材词表和 Excel 的四套对照练习均保留，避免用较短的表格覆盖教材新增内容。对照练习默认逐词朗读。
- 来源目录共 **141 条 MP3**，全部收录在音频目录。听写页选择与本练习相对应的录音；横向词表不绑定纵向录音，避免题目顺序混用。
- 第 1 章是学习方法，不单列听写练习。第 8 章 `8.7-3` 的一个日期在答案栏为 `26 June, 1957`，朗读栏为 `28 June, 1957`，两种答案均接受。

来源：[27rabbit-penguin/IELTS_repo](https://github.com/27rabbit-penguin/IELTS_repo)，固定版本 `4712d0513918d2f75b1a629b97edd602e8d636d8`。新增内容从扫描 PDF 提取并与页面/第二套识别结果校对；扫描和教材本身仍可能存在个别笔误。原有音标和释义继续沿用，新增条目未核对的音标与释义留空，不用自动生成内容填充。教材与录音可能存在版本差异，尤其第 11 章，请按对应版本练习。

教材和音频版权归原作者所有，本项目用于个人学习。

## 数据与页面分离

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构 |
| `assets/styles.css` | 原有视觉样式与播放器适配 |
| `assets/app.js` | 听写、播放、批改、草稿、错题和导入导出 |
| `data/corpus.json` | 当前使用的章节和答案 |
| `data/audio.json` | 录音地址、来源路径、章节与文件大小 |
| `data/legacy-vocab.json` | 原词库快照，供校对与后续迁移参考，页面不加载 |
| `data/README.md` | 数据格式与维护约定 |

维护词条只需编辑 JSON，不需要修改页面或 JavaScript。更换音频托管地址只需编辑 `data/audio.json`。

## 验证

```bash
python3 scripts/validate_data.py
node --check assets/app.js
```

浏览器集成检查需要 Python Playwright 和本机 Chrome，先启动静态服务器：

```bash
python3 -m pip install playwright
python3 scripts/browser-smoke.py
```

通过 `WL_CHROME` 指定 Chrome 路径，通过 `WL_TEST_URL` 指定测试地址。检查覆盖页面加载、听写批改、重复提交、刷新恢复、错题朗读调用、掌握状态、CSV 导出、旧数据迁移、导入及手机布局。该检查用替身隔离远程音频与系统语音；真实音频加载另行验证。
